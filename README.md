# Tic-Tac-Toe Download Page

A simple GitHub Pages landing page for the Tic-Tac-Toe Windows application.

## Publish

1. Put `index.html` in the root of your GitHub repository.
2. Put your executable in the same folder as `index.html`.
3. Ensure the executable filename is exactly `Tic-Tac-Toe.exe`, or edit the `href` in `index.html` to match your filename.
4. In GitHub, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**, select your branch (usually `main`) and folder `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site. The URL is usually `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

Note: GitHub repositories have file-size limits. If the EXE is too large or you prefer a cleaner repository, upload it to a GitHub Release and link to that release asset instead.
